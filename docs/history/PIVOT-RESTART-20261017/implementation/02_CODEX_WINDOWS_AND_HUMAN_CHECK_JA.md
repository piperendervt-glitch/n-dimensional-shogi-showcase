## まず設定を変更して確認する

1. 開始メニューで「オプション」を選ぶ。「設定（オプション）」が開き、中央の駒表示と右側の設定欄が読めることを確認する。
2. 「駒の動き設定」から「王（玉将）」を選び、「全方向（全近傍）」と「軸方向のみ」を切り替える。中央の移動候補と件数が変わり、視点・断面・右欄のスクロール位置が勝手に初期化されないことを確認する。件数は現在の配置と断面によるので、固定数だけで合否を判断しない。
3. 「使用する軸」のWを外して戻す。王の候補が変わり、他の駒や盤の次元そのものが消されないことを確認する。
4. 「同時に動かす最大軸数」の欄をクリックし、対応する値（例：1または4）を入力して欄の外をクリックする。文字入力中に背後の駒や視点が動かないことを確認する。確認後は「全方向（全近傍）」で戻せる。
5. 「選択」で表示中の駒をクリックする。金色の選択枠がその駒の断面に合うことを確認する。青い候補へ試し移動し、必要なら「Undo」で戻す。「試し配置」の変更は対局の初期配置へ自動採用されない。

Gは移動定義に合う盤内候補、Pは経路・占有・捕獲条件を含む候補。完全合法性L・詰みの評価とは区別する。固定・未対応と表示された駒の能力を、編集できたと解釈しない。
