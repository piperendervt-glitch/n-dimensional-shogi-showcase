# 再実行中の限定した実装判断

2026-10-17。依頼原本のハッシュを変更せず、発見した接続欠落への修正理由を記録する。製品ルールの追加採用ではない。

## D01 設定画面で中心移動と原点復帰を操作可能にする

独立レビューで、設定画面は承認済みXY/XZ/XW/YZの2D小窓である一方、中心移動とHome入力がプレイ専用の非表示3D小窓へのhoverに限定され、設定中に操作できないことが判明した。

設定の2D小窓を保持し、既存XYZWギズモの軸を共通の世界4D軸移動へ接続する。クリックは従来の基準断面選択、移動閾値を超えたドラッグは中心移動だけにする。Home/Shift+Homeは中央プレビューまたは既存ギズモ上でも使えるようにする。フォーム編集中は受け付けず、プレイの小窓操作は保持する。

新しい常設ボタンを増やさず、設定中の操作可能性と保存往復を実現する限定修正。論理駒・G/Pを動かさず、同じ移動量は同じC/Aを得ること、click/dragの同時発火がないこと、フォームへの入力非干渉、O/P復帰、保存再読込を試験する。

実装担当はこの案を採用すると回答済み。実際の変更ファイルと結果はimplementation配下の台帳に記録する。この判断記録自体は試験PASSではない。

## D02 画面切替と入力所有

右ドラッグ中に左クリックでメニューへ移れる経路があり、後続の取消が別セッションの可変sliceへ作用し得る。画面切替前に元の操作を取消し、ドラッグ開始時に捕捉した対象へ復元する。操作所有中のフォーム・ボタンを制御し、フォーカス喪失・画面切替・Escapeを同じ取消条件で確認する。

## D03 空断面とクリックの試験を実仕様へ合わせる

初期40駒のXYW基準断面は、中央Z列に初期駒が存在しないfixtureでは空になる。すべての基準断面で駒数が正であるという試験前提をやめ、独立に求めた交差・非交差と古いメッシュの消去を確認する。クリックは別選択または未選択からのPieceId変化で確認し、駒だけでなく選択セル枠・既知三角形点・hitの一致を測る。失敗試験を削除して成功とする変更はしない。
