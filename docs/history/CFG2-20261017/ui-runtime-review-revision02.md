## 発見した問題と次版向け修正

1. 初期対局で物理板40駒と空中40駒が同時に見え、80駒あるように受け取られる。親担当が安定XYZ/中心0対局だけ空中木駒を省略する方針を採用。`CfgPreviewRenderer.ShowPieces`（旧既定true）を追加し、falseで描画と木駒pickを一致して無効化した。断面セル・G/P・候補表示は保持。回転/移動/他姿勢は空中実切断を表示する。
2. 物理板上の空候補セルへ向けたrayが空中候補の前面に遮られる。親担当が板面P候補のクリック経路を追加。表示補助として `RefreshBoardCandidates(p,selected,visible)` を追加した。V=W=0・盤内の実Q4のみを薄青タイルと青輪郭、選択を金で表示。板上0.8mmの同一平面、セル幅0.93倍。集合の投影・架空の候補追加はしない。
3. 初期40駒の小窓木iconが密集帯になっている。7×9pxから3.5×4.5pxへ縮小し、固定軸条件に実駒数を追加した。新画像で可読性を再確認する。
4. メニューの3駒が大きく浮き、空の盤と格子が主役になっている。親担当が3駒を物理板へ置き、メニューの全Gridと空中木駒を省略する修正を担当。メニュー時は残ったG/P/攻撃面も消す必要があることを共有した。
5. 駒一覧の金・銀・桂・香の「固定定義」が折り返している。親担当が一覧を短名にし、詳細へ説明を寄せる。
6. 設定背景に直前のメニュー文字の残像が見える。親担当が独立背景カメラで修正する。
